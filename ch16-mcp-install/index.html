第 16 章 · Part 6：MCP Plugin

安裝 MCP Server

三步驟：安裝套件、設定 settings.json、重啟 Claude Code。

設定位置

MCP Server 在 ~/.claude/settings.json 的 mcpServers 區塊設定：

~/.claude/settings.json 結構 
{
  "mcpServers": {
    "server-name": {
      "command": "node",
      "args": ["/path/to/server/index.js"],
      "env": {
        "API_KEY": "your-key"
      }
    }
  }
}

範例 1：Filesystem Server

讓 Claude 可以讀寫指定目錄的檔案（比內建 Read/Write 工具更有彈性的存取控制）：

bash — 安裝 
npm install -g @modelcontextprotocol/server-filesystem
~/.claude/settings.json 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:/VSCode_Proj",
        "C:/Obsidian/vault"
      ]
    }
  }
}

設定後，Claude 可以呼叫 read_file、write_file、list_directory 等工具，且只能存取你指定的目錄。

範例 2：GitHub Server

bash — 安裝 
npm install -g @modelcontextprotocol/server-github
~/.claude/settings.json 
{
  "mcpServers": {
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_your_token_here"
      }
    }
  }
}

設定後 Claude 可以：建立 Issue、列出 PR、讀取 commit 歷史、搜尋程式碼等。

範例 3：Playwright 瀏覽器自動化

bash — 安裝 
npm install -g @executeautomation/playwright-mcp-server
npx playwright install
~/.claude/settings.json 
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@executeautomation/playwright-mcp-server"]
    }
  }
}

設定後 Claude 可以：開啟網頁、點擊、填表、截圖、等待元素載入——直接在對話中完成 E2E 測試。

完整 settings.json 範例

~/.claude/settings.json（多個 MCP） 
{
  "mcpServers": {
    "filesystem": {
      "command": "npx",
      "args": [
        "-y",
        "@modelcontextprotocol/server-filesystem",
        "C:/VSCode_Proj"
      ]
    },
    "github": {
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-github"],
      "env": {
        "GITHUB_PERSONAL_ACCESS_TOKEN": "ghp_..."
      }
    },
    "playwright": {
      "command": "npx",
      "args": ["-y", "@executeautomation/playwright-mcp-server"]
    }
  },
  "hooks": {
    "SessionEnd": [
      {
        "hooks": [{ "type": "command", "command": "powershell -File ~/.claude/hooks/write-diary.ps1" }]
      }
    ]
  }
}

💡
MCP Server 連線失敗？

執行 /mcp 確認狀態，或用 /doctor 診斷。常見原因：套件未安裝（用 npm install -g）、env 變數未設、路徑錯誤。Windows 注意路徑用正斜線或雙反斜線。
