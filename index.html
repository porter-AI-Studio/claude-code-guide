⚡
快速入門
一行指令安裝，5 分鐘上手。支援 Windows、macOS、Linux。

三大模型

讓 Claude 記住你的專案規則、縮寫、偏好設定，不用每次重複說明。

Hooks 自動化
在工具執行前後觸發自訂腳本，自動寫日誌、阻擋危險操作。
🛠️
Skills 擴充
官方六大類 Skills + 自己寫 Skill，把常用工作流程封裝成 Slash Command。
🔌
MCP Plugin
連接任何 API 成為 Claude 工具，打造專屬的 AI 工作環境。
