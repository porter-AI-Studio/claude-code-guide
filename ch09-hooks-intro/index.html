第 9 章 · Part 4：Hooks

Hooks 是什麼？

Hooks 是 Claude Code 的生命週期攔截器——在 CC 執行的各個節點插入你自己的邏輯，從自動化日誌、安全防護到桌面通知，全部交給 Hooks 處理。

什麼是 Hooks？

每次 Claude Code 執行工具、回應使用者、或開始／結束 session 時，都會觸發一系列生命週期事件。Hooks 讓你可以在這些事件點掛上自己的腳本或服務，實現：

  • 自動記錄每次 session 的工作摘要
  • 阻擋危險指令（如 rm -rf）在執行前被攔截
  • 任務完成時送出桌面通知
  • 審計日誌——記錄所有執行過的 Bash 指令
  • 自動化工作流程——呼叫外部 Webhook 或 MCP 工具

與 CLAUDE.md 規則不同，Hooks 是技術層面的強制執行，不依賴 Claude 的理解與自覺——腳本說不行就不行。

觸發事件一覽表

PreToolUse
工具執行前（可阻擋）
安全檢查、危險指令攔截
PostToolUse
工具執行成功後
審計日誌、結果通知
PostToolUseFailure
工具執行失敗後
錯誤告警、自動重試邏輯
UserPromptSubmit

輸入過濾、自動補充 context
Stop
每次 agent 回應結束後
寫工作日誌、通知任務完成
SessionEnd
整個 session 關閉時

Hook 類型

類型 說明 適用情境
command 執行本機 shell 腳本 日誌、安全檢查、本機通知
http POST 請求到 Webhook URL Slack 通知、CI/CD 觸發、外部 API
mcp_tool 呼叫已連接的 MCP 工具 整合 MCP 服務、資料庫寫入
prompt 讓 LLM 評估或生成內容 自動摘要、AI 審核輸入內容
agent 啟動 subagent 執行子任務 複雜後處理、多步驟自動化

基本設定範例

所有 Hooks 設定都寫在 ~/.claude/settings.json 的 hooks 欄位。以下是一個最簡單的範例——每次 Claude 回應結束後，執行一個腳本：

~/.claude/settings.json 
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/on-stop.sh"
          }
        ]
      }
    ]
  }
}

如果想讓 Hook 只在特定工具觸發，可以加上 matcher：

~/.claude/settings.json（加上 matcher） 
{
  "hooks": {
    "PreToolUse": [
      {
        "matcher": "Bash",
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/check.sh"
          }
        ]
      }
    ]
  }
}

Stdin / Stdout 資料格式

Hook 腳本透過 stdin 接收事件資料（JSON 格式），並可透過 stdout 回傳決策。

PreToolUse 的 stdin 範例

stdin（Hook 腳本接收到的資料） 
{
  "tool_name": "Bash",
  "tool_input": {
    "command": "rm -rf /"
  },
  "session_id": "sess_abc123xyz"
}

PostToolUse 的 stdin 範例

stdin（工具執行後） 
{
  "tool_name": "Bash",
  "tool_input": {
    "command": "ls -la"
  },
  "tool_result": "total 48
drwxr-xr-x  8 user user 4096 ...",
  "session_id": "sess_abc123xyz"
}

阻擋工具執行

在 PreToolUse 事件中，Hook 腳本可以阻擋工具執行：

  • exit code 0 — 允許執行，繼續往下
  • exit code 2 — 阻擋執行，將 stderr 輸出顯示給 Claude

腳本也可以輸出 JSON 到 stdout 來提供更詳細的阻擋原因：

stdout（阻擋時輸出） 
{
  "decision": "block",
  "reason": "Dangerous command detected: rm -rf /"
}

完整的阻擋腳本範例（bash）：

~/.claude/hooks/check.sh 
#!/bin/bash
INPUT=$(cat)
COMMAND=$(echo "$INPUT" | python3 -c "import sys,json; print(json.load(sys.stdin)['tool_input']['command'])")

if echo "$COMMAND" | grep -qi "rm -rf /"; then
  echo '{"decision":"block","reason":"拒絕執行：rm -rf / 是危險指令"}' >&2
  exit 2
fi

exit 0
💡
Hooks 不影響對話速度

除了 PreToolUse 以外，所有 Hook 都在 Claude 回應之後才執行，不會拖慢對話的回應時間。PreToolUse 雖然在執行前觸發，但通常腳本執行速度極快（毫秒級），使用者感受不到延遲。
