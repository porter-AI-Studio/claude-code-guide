第 5 章 · Part 2：模型選擇

如何切換模型

三種切換方式，因應不同場景靈活調整。

方式 1：互動式 /model 指令

在互動模式中輸入 /model，會顯示選單讓你選擇：

You: /model

Select a model:
claude-sonnet-4-6 (目前)
claude-haiku-4-5
claude-opus-4-8
claude-sonnet-4-5
...

# 或直接帶參數
You: /model claude-opus-4-8
✓ 已切換到 claude-opus-4-8

使用 /model 切換後，設定會成為這個 session 的新預設，下次啟動 claude 時會記住。

方式 2：命令列 --model 參數

啟動時直接指定模型，適合臨時切換或腳本使用：

bash 
# 啟動互動模式時指定模型
claude --model claude-opus-4-8

# 單次指令指定模型
claude --model claude-opus-4-8 "設計這個購物車系統的資料庫架構"

# 使用縮寫（claude-code 也接受部分名稱）
claude --model opus "分析這段程式碼的安全漏洞"
claude --model haiku "把這個變數名改成駝峰式命名"
claude --model sonnet "重構 src/auth/ 目錄"

方式 3：CLAUDE.md 設定預設模型

在 CLAUDE.md 中設定預設模型，讓特定專案永遠使用指定模型：

~/.claude/CLAUDE.md 或 ./CLAUDE.md 
# 設定預設模型
## 預設設定
- 預設模型：claude-sonnet-4-6

# 或針對不同類型任務說明
## 模型使用原則
- 日常開發使用 Sonnet
- 架構設計任務請切換到 Opus：`/model claude-opus-4-8`
- 快速問答可切換到 Haiku：`/model claude-haiku-4-5`
ℹ️
CLAUDE.md 中的模型設定

CLAUDE.md 裡的模型設定是給 Claude 看的「提醒」，真正改變預設模型需要透過 /model 指令或 --model 參數。不過把使用原則寫在 CLAUDE.md 可以讓 Claude 在適當時機建議你切換。

方式 4：/config 設定介面

透過圖形設定介面永久變更預設模型：

互動模式 
You: /config
# 開啟設定介面，找到 "Default Model" 項目修改

確認目前使用的模型

互動模式 
You: /status

Status:
  Version:   2.1.x
  Model:     claude-sonnet-4-6  ← 目前模型
  Account:   your@email.com
  Directory: /your/project

也可以看互動介面頂端，通常會顯示目前使用的模型名稱。

使用情境速查

情境推薦做法
這個任務想用更強的模型 互動模式中輸入 /model claude-opus-4-8
這次啟動要用特定模型 claude --model haiku "..."
腳本/CI 需要固定模型 claude --model claude-haiku-4-5 --print "..."
整個專案預設用 Opus 在 ./CLAUDE.md 中寫明，並執行一次 /model claude-opus-4-8
想切回預設 /model claude-sonnet-4-6
💡
省錢技巧：任務分流

同一個工作 session 中，你可以針對不同步驟切換模型。例如：先用 Opus 做架構設計，確認方向後切到 Sonnet 實作，最後用 Haiku 快速補充測試和文件。
