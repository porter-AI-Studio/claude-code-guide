第 3 章 · Part 1：入門

第一次對話

三種啟動方式、基本操作流程，以及你會一直用到的 Slash Commands。

三種啟動方式

根據使用情境選擇適合的啟動方式：

bash 
# 方式 1：互動模式（REPL）——最常用
claude

# 方式 2：單次指令——適合快速任務
claude "解釋 src/auth.ts 這個檔案的作用"

# 方式 3：Headless 模式——適合腳本、CI/CD
claude --print "列出這個專案所有的 API endpoint"
模式指令適用情境
互動 REPL claude 日常開發、多輪對話、複雜任務
單次指令 claude "..." 快速查詢、一次性任務
Headless claude --print "..." 腳本整合、CI/CD pipeline、輸出管道

常用 Slash Commands

在互動模式中輸入 / 開頭的指令來控制 Claude Code 的行為。以下是最常用的：

對話控制

指令說明
/clear開新對話，清除目前的對話歷史
/compact壓縮對話歷史，節省 token 用量，適合長時間工作
/context視覺化顯示目前 context 使用量（還剩多少空間）
/rewind回滾到上一個 checkpoint（如果上一步改壞了可用）

模型與設定

指令說明
/model切換 AI 模型（Haiku / Sonnet / Opus）
/model claude-opus-4-8直接切換到指定模型
/config開啟設定介面
/theme更換介面顏色主題

資訊查詢

指令說明
/help顯示所有可用指令說明
/usage查看目前 session 的 token 用量與費用
/status查看版本、目前模型、登入帳號
/doctor診斷安裝與連線問題

記憶與設定檔

指令說明
/memory查看與管理 CLAUDE.md 及跨對話記憶
/init自動分析專案並產生 CLAUDE.md（新專案推薦）
/permissions管理工具執行權限（允許/拒絕特定操作）

鍵盤快速鍵

按鍵功能
Enter送出訊息
Shift+Enter換行（多行輸入）
↑ / ↓瀏覽輸入歷史
Ctrl+C中斷目前執行中的任務
Ctrl+C ×2離開 Claude Code
Esc取消目前輸入

常見第一次操作範例

讓 Claude 認識你的專案

互動模式 
You: /init

Claude 會自動掃描你的專案結構、讀取 package.json、README.md 等檔案，然後生成一份 CLAUDE.md。這是快速讓 Claude 了解新專案的最佳方式。

請 Claude 說明一段程式碼

bash 
claude "解釋 src/middleware/auth.ts 這個檔案是怎麼運作的"

修復錯誤

bash 
claude "執行 npm test，如果有失敗的測試就修正它"

新增功能

互動模式 
You: 在 src/api/users.ts 加一個 GET /users/:id/profile 的 endpoint，
要驗證使用者身份，並回傳使用者的基本資料和最近 5 筆活動紀錄
💡
指令越具體，結果越好

不要只說「修好這個 bug」，而是說「執行 npm test，找到 UserService.test.ts 失敗的原因，修正 src/services/user.ts 中的問題」。具體的指令能讓 Claude 更準確地執行任務。

費用追蹤

每次對話結束後，使用 /usage 查看本次 session 的花費：

互動模式 
You: /usage

Session Usage:
  Input tokens:    24,832
  Output tokens:   3,156
  Cache read:      18,204
  Estimated cost:  ~$0.08

養成定期查看的習慣，避免意外的高額費用。使用快取（Cache read）能大幅降低費用。

如何離開

bash 
# 方式 1：Slash command
/exit

# 方式 2：連按兩次 Ctrl+C
^C^C

# 方式 3：輸入 exit 或 quit
exit
