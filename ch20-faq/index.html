第 20 章 · Part 7：進階技巧

常見問題 & Debug

遇到問題不要慌。大多數 Claude Code 的問題都有固定的排查步驟。

第一步：永遠先跑 /doctor

You:/doctor
Checking installation...
✓Claude Code v2.1.x
✓Node.js v24.x
✗Authentication: not logged in ← 問題找到了
✓Network: connected
✓MCP servers: 2/3 connected
Press 'f' to auto-fix detected issues

f 鍵自動修復大多數常見問題。

安裝問題

Windows：irm 安裝失敗

powershell 
# 如果 irm | iex 失敗，改用 WinGet
winget install Anthropic.ClaudeCode

# 或 npm 方式
npm install -g @anthropic-ai/claude-code

npm 安裝後找不到 claude 指令

bash 
# 確認 npm global bin 在 PATH 中
npm config get prefix

# 加入 PATH（Linux/macOS）
export PATH="$(npm config get prefix)/bin:$PATH"

# Windows PowerShell
$env:PATH += ";$(npm config get prefix)"

# 重新安裝
npm install -g @anthropic-ai/claude-code

登入 / 認證問題

API Key 無效

bash 
# 確認環境變數是否設定
echo $ANTHROPIC_API_KEY  # macOS/Linux
$env:ANTHROPIC_API_KEY   # Windows PowerShell

# 重新登入
claude /logout
claude  # 重新走登入流程

claude.ai 帳號登入後 token 不足

切換到 API Key 方式，或升級 claude.ai 方案。也可以用 /usage-credits 設定超量使用額度。

執行時期問題

Context 超限（對話太長）

互動模式 
# 壓縮對話歷史
You: /compact

# 或開新 session
You: /clear

# 查看目前使用量
You: /context

Claude 卡住不回應

操作步驟 
1. 按 Ctrl+C 中斷目前執行
2. 如果無效，再按一次 Ctrl+C 退出
3. 重新啟動：claude
4. 用 /resume 恢復上次對話（若需要）

工具執行被 Hook 阻擋

互動模式 
# 查看哪個 hook 觸發了阻擋
You: /hooks

# 臨時停用特定 hook（在 settings.json 中加上 "disabled": true）
# 或執行 /doctor 診斷 hook 問題

MCP 連線問題

互動模式 
# 查看 MCP 狀態
You: /mcp

# 常見原因：
# 1. 套件未安裝：npm install -g <mcp-server>
# 2. 路徑錯誤：確認 args 中的路徑
# 3. env 未設定：確認 settings.json 的 env 區塊
# 4. 語法錯誤：JSON 格式不對（用 /doctor 檢查）

效能與費用問題

費用異常高

互動模式 
# 查看本次 session 費用
You: /usage

# 降低費用的方法：
# 1. 切換到 Haiku：/model claude-haiku-4-5
# 2. 定期 /compact 壓縮對話
# 3. 避免反覆讀取大型檔案
# 4. 用 --print 模式取代互動模式

回應很慢

切換到 Haiku 模型（速度最快），或用 /fast 開啟快速模式：

互動模式 
You: /fast on   # 開啟快速模式
You: /model claude-haiku-4-5  # 切換最快模型

版本管理

bash 
# 查看目前版本
claude --version

# 更新到最新版
claude update

# 查看 changelog
claude /release-notes

回報問題

互動模式 
# 回報 bug 或提供意見
You: /feedback

# 或直接到 GitHub
# https://github.com/anthropics/claude-code/issues
💡
Debug 心法

先 /doctor，再 /status 確認模型與帳號，最後看 /usage 確認 token 用量。九成的問題都能在這三步找到原因。
