第 2 章 · Part 1：入門

安裝與環境設定

兩種安裝方式，五分鐘內完成。支援 Windows、macOS、Linux。

系統需求

項目需求
作業系統macOS 13+、Windows 10 1809+、Ubuntu 20.04+、Debian 10+
硬體RAM 4 GB+，x64 或 ARM64 處理器
網路需要連線（與 Anthropic API 通訊）
帳號claude.ai 帳號 或 Anthropic API Key（二選一）
Node.js僅 npm 安裝方式需要 v18+

方法一：Native Install（推薦）

不需要 Node.js，支援自動背景更新，官方推薦方式。

macOS / Linux / WSL

bash 
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell

powershell 
irm https://claude.ai/install.ps1 | iex

Windows 套件管理器

powershell 
# WinGet
winget install Anthropic.ClaudeCode

# Homebrew（macOS）
brew install --cask claude-code

方法二：npm 安裝

需要 Node.js v18 以上。適合已有 Node.js 開發環境的使用者。

bash 
# 全域安裝
npm install -g @anthropic-ai/claude-code

# 驗證安裝版本
claude --version
❯ npm install -g @anthropic-ai/claude-code
added 124 packages, and audited 125 packages in 3s
❯ claude --version
0.2.29
Claude Code is ready. Type 'claude' to start.
💡
哪種方式比較好？

Native Install 支援自動更新，不依賴 Node.js 版本，建議優先選用。npm 安裝適合在 CI/CD 環境或已有 Node.js 的工作流中整合。

第一次啟動與登入

安裝完成後，執行 claude 進行登入設定。有兩種方式：

方式 A：使用 claude.ai 帳號（推薦新手）

bash 
claude

首次執行會自動開啟瀏覽器，引導你完成 OAuth 授權。登入 claude.ai 帳號即可，不需要另外取得 API Key。

方式 B：使用 Anthropic API Key

前往 console.anthropic.com 建立 API Key，然後：

bash (macOS / Linux) 
# 臨時設定（目前 session 有效）
export ANTHROPIC_API_KEY="sk-ant-api03-..."

# 永久設定（加到 ~/.zshrc 或 ~/.bashrc）
echo 'export ANTHROPIC_API_KEY="sk-ant-api03-..."' >> ~/.zshrc
source ~/.zshrc
powershell (Windows) 
# 目前 session 有效
$env:ANTHROPIC_API_KEY = "sk-ant-api03-..."

# 永久設定（寫入使用者環境變數）
[System.Environment]::SetEnvironmentVariable(
  "ANTHROPIC_API_KEY",
  "sk-ant-api03-...",
  "User"
)
⚠️
不要把 API Key 放進程式碼

永遠不要將 ANTHROPIC_API_KEY 直接寫在程式碼中或 commit 進 git。建議加入 .gitignore 後使用 .env 檔案管理。

常見安裝問題排解

ℹ️
Windows PowerShell Execution Policy 錯誤

如果在 Windows 執行 irm ... | iex 時出現「無法載入檔案，因為這個系統上已停用執行指令碼」的紅色錯誤，請先以**系統管理員身分**開啟 PowerShell 並執行以下指令來開放權限：

Set-ExecutionPolicy RemoteSigned -Scope CurrentUser

設定完成後再重新執行安裝指令即可。

驗證安裝是否正常

bash 
# 查看版本
claude --version

# 健康診斷（會自動檢查並提示修復）
claude /doctor

/doctor 是 Claude Code 內建的診斷工具，會檢查安裝、登入狀態、網路連線等，有問題時按 f 自動修復。

VS Code 整合

安裝 VS Code Extension 後，可以在 VS Code 側邊欄直接使用 Claude Code，不需要切換到終端機。

  1. 開啟 VS Code，前往 Extensions（Ctrl+Shift+X）
  2. 搜尋 Claude Code（發行者：Anthropic）
  3. 點擊安裝
  4. 安裝後在側邊欄會出現 Claude 圖示
💡
其他 IDE 支援

除了 VS Code，Claude Code 也支援 JetBrains IDE（IntelliJ、PyCharm、WebStorm 等），以及 claude.ai 網頁版。

手動更新

bash 
# 在 Claude Code 互動介面中執行
claude update

# 或使用 npm（若以 npm 安裝）
npm update -g @anthropic-ai/claude-code

Native Install 方式會在背景自動更新，通常不需要手動執行。
