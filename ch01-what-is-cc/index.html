第 1 章 · Part 1：入門

什麼是 Claude Code？

一個讓 AI 真正「動手」的工具——不只回答問題，而是直接讀取、修改、執行你的程式碼。

一句話定義

Claude Code 是 Anthropic 官方開發的 CLI（命令列介面）工具， 讓 Claude AI 能夠在你的終端機中直接存取檔案系統、執行指令、操作 Git， 以及呼叫各種外部工具——不需要複製貼上，不需要切換視窗。

簡單說：你打一句話，Claude 就去做事。改完告訴你結果。

ℹ️
官方定義

Claude Code 是 Anthropic 推出的 agentic coding tool，讓開發者透過自然語言與 Claude 協作，完成真實的程式碼任務。

代理式 CLI：跟傳統工具差在哪？

傳統的程式設計輔助工具（ChatGPT、GitHub Copilot）是對話型的——你貼上程式碼，它給你建議，你再手動套用。

Claude Code 是代理式（Agentic）的——它能自己主動決定要用哪些工具、以什麼順序執行，直到任務完成。

功能 ChatGPT / Copilot Claude Code
讀取真實檔案 ❌ 需要手動貼上 ✅ 直接讀整個專案
修改並儲存檔案 ❌ 只給建議 ✅ 直接編輯儲存
執行終端機指令 ❌ ✅ 可執行 shell 命令
Git 操作 ❌ ✅ commit、diff、branch
理解整個程式庫 △ 需要你提供上下文 ✅ 自動掃描相關檔案
多步驟自動化 ❌ 一次一個問題 ✅ 規劃並連續執行

能做什麼？

Claude Code 配備超過 400 個工具，常見使用場景包括：

  • Bug 修復——描述問題，Claude 找到原因並直接修改
  • 新功能開發——從設計到實作，一氣呵成
  • 大型重構——跨多個檔案的系統性修改
  • 說明文件——自動產生 README、API 文件、程式碼註解
  • 測試撰寫——分析程式碼、生成對應的單元測試
  • Debug 輔助——執行測試、分析錯誤訊息、提出修正
  • 程式碼審查——找出潛在問題、安全漏洞、效能瓶頸
  • Git 工作流——生成 commit message、管理分支

查詢迴圈（Agent Loop）

Claude Code 的核心是一個非同步查詢迴圈。當你輸入一個指令，它不是執行一次就結束， 而是持續循環：呼叫模型 → 收到工具指令 → 執行工具 → 把結果回傳給模型 → 再次呼叫…… 直到任務完成或你叫停。

↓

↓

回到 API 繼續推理

這就是「代理式」的本質——Claude 自己決定下一步要做什麼。

💡
跟傳統 CLI 的根本差異

grep 不會自己決定順便執行 sed。但 Claude Code 會。這份「自主判斷」是它強大的原因，也是你需要理解它的權限系統的原因（見 Ch07 Permissions）。

誰適合用 Claude Code？

  • 想加速日常開發工作的工程師
  • 需要快速了解陌生程式庫的開發者
  • 做側專案但時間有限的人
  • 想把重複性工作自動化的技術人員
  • 任何想把 AI 真正融入開發流程的人
⚠️
注意

Claude Code 可以讀寫你的檔案、執行 shell 指令。使用前請了解權限與 Rules 設定，避免意外操作。
