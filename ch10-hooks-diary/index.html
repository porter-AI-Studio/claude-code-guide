第 10 章 · Part 4：Hooks

實戰：自動寫工作日誌

每次 CC session 結束時，自動把工作紀錄寫入 Obsidian 日誌——不需要手動整理，Hooks 全程代勞。

目標

這個章節要實作一個真實的 Hooks 應用：每次 Claude Code session 結束時，自動把 session 摘要追加到今日的 Obsidian 工作日誌，路徑為：

工作日誌路徑 
C:\Obsidian\vault\工作日誌\YYYY-MM-DD.md

完成後的效果：

  • 打開 CC、做事、關掉——日誌自動更新
  • 每個 session 留下時間戳記、工作目錄、Session ID
  • 完全不需要手動複製貼上

Step 1：建立 Hook 腳本

先建立腳本目錄（若不存在）：

Terminal 
mkdir -p ~/.claude/hooks

建立 PowerShell 腳本 ~/.claude/hooks/write-diary.ps1：

~/.claude/hooks/write-diary.ps1 
# 從 stdin 讀取 session 資料
$data = $input | ConvertFrom-Json
$date = Get-Date -Format "yyyy-MM-dd"
$diaryPath = "C:\Obsidian\vault\工作日誌\$date.md"

# 準備要寫入的內容
$entry = @"

---
## Claude Code Session - $(Get-Date -Format "HH:mm")
- Session ID: $($data.session_id)
- 工作目錄: $($data.cwd)
整理人：Claude Code & Porter
"@

Add-Content -Path $diaryPath -Value $entry -Encoding UTF8

腳本說明：

  • $input | ConvertFrom-Json — 讀取 CC 透過 stdin 傳入的 session 資料
  • Get-Date -Format "yyyy-MM-dd" — 取得今日日期，組成日誌檔案路徑
  • Add-Content — 追加到檔案末尾（不覆蓋），確保 UTF-8 編碼

Step 2：設定 settings.json

在 ~/.claude/settings.json 加入 Stop Hook，讓腳本在每次 agent 回應結束後觸發：

~/.claude/settings.json 
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "powershell -NonInteractive -File ~/.claude/hooks/write-diary.ps1"
          }
        ]
      }
    ]
  }
}

如果你的環境是 macOS / Linux，改用 bash 腳本：

~/.claude/settings.json（Linux/macOS） 
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/write-diary.sh"
          }
        ]
      }
    ]
  }
}

Step 3：驗證

測試流程：

  1. 開啟 Claude Code：claude
  2. 隨便說幾句話，例如「幫我列出目前目錄的檔案」
  3. 按 Ctrl+C 或輸入 /exit 結束 session
  4. 檢查今日日誌檔案是否已更新：
PS C:\> $date = Get-Date -Format "yyyy-MM-dd"
PS C:\> Get-Content "C:\Obsidian\vault\工作日誌\$date.md" -Tail 5
--- ## Claude Code Session - 14:35 - Session ID: sess_abc123xyz - 工作目錄: C:\VSCode_Proj\my-project 整理人：Claude Code & Porter

進階：讓 Claude 寫摘要

上面的腳本只記錄 metadata（session ID、目錄）。如果你想要讓 Claude 自動總結這次 session 做了什麼，可以改用 prompt 類型的 Hook：

~/.claude/settings.json（使用 prompt 類型） 
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "prompt",
            "prompt": "請用 2-3 句繁體中文總結這次 session 完成了什麼工作，格式為條列式。然後呼叫 write_diary 工具把摘要寫入今日工作日誌。"
          }
        ]
      }
    ]
  }
}

prompt 類型會讓 CC 在 session 結束時，用目前對話的完整 context 執行一次額外的 LLM 推理，生成摘要後再寫入日誌。這樣每篇日誌都會有清楚的工作記錄，而不只是 metadata。

組合使用：先跑腳本，再生成摘要

~/.claude/settings.json（組合 command + prompt） 
{
  "hooks": {
    "Stop": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "powershell -NonInteractive -File ~/.claude/hooks/write-diary.ps1"
          },
          {
            "type": "prompt",
            "prompt": "用一句話總結這次對話的主要成果，追加到今日工作日誌。"
          }
        ]
      }
    ]
  }
}

自動 Git Staging

每次 Claude 編輯完檔案，自動執行 git add——不再需要手動暫存，最終只要確認 commit 訊息就好。

~/.claude/hooks/auto-stage.sh 
#!/bin/bash
INPUT=$(cat)
FILE_PATH=$(echo "$INPUT" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('tool_input',{}).get('file_path',''))")
[ -z "$FILE_PATH" ] && exit 0

PROJECT_DIR="$CLAUDE_PROJECT_DIR"
[ -z "$PROJECT_DIR" ] && PROJECT_DIR="$(pwd)"
cd "$PROJECT_DIR" || exit 0

git add "$FILE_PATH" 2>/dev/null || true
exit 0
~/.claude/settings.json（auto-stage） 
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit",
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/auto-stage.sh"
          }
        ]
      }
    ]
  }
}

Token 使用量追蹤

每次工具呼叫結束後，把工具名稱與時間戳記追加到 CSV 檔——方便事後分析哪些工具最耗資源。設定 async: true 讓日誌在背景寫入，不阻擋主流程。

~/.claude/hooks/cost-logger.py 
#!/usr/bin/env python3
import json, sys, os, csv
from datetime import datetime

data = json.load(sys.stdin)
log_file = os.path.expanduser("~/.claude/cost-log.csv")
row = [
    datetime.now().strftime("%Y-%m-%d %H:%M:%S"),
    data.get("tool_name", ""),
    data.get("session_id", ""),
]
with open(log_file, "a", newline="", encoding="utf-8") as f:
    csv.writer(f).writerow(row)
~/.claude/settings.json（cost-logger，async: true） 
{
  "hooks": {
    "PostToolUse": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "python3 ~/.claude/hooks/cost-logger.py",
            "async": true
          }
        ]
      }
    ]
  }
}

日誌範例：

~/.claude/cost-log.csv 
2026-06-10 09:15:33,Read,sess_abc123
2026-06-10 09:15:41,Bash,sess_abc123
2026-06-10 09:15:55,Edit,sess_abc123
2026-06-10 09:16:10,Bash,sess_abc123

編輯後自動格式化

Claude 修改完程式碼後，自動用對應格式化工具整理風格——依副檔名選擇 prettier（JS/TS/CSS）、black（Python）或 gofmt（Go）。無論 Claude 的縮排習慣如何，輸出永遠符合你的 code style。

~/.claude/hooks/format-after-edit.sh 
#!/bin/bash
INPUT=$(cat)
FILE_PATH=$(echo "$INPUT" | python3 -c "import sys,json; d=json.load(sys.stdin); print(d.get('tool_input',{}).get('file_path',''))")
[ -z "$FILE_PATH" ] && exit 0

EXT=$(python3 -c "import sys; f=sys.argv[1]; print(f.rsplit('.',1)[-1].lower() if '.' in f else '')" "$FILE_PATH")

case "$EXT" in
  js|ts|jsx|tsx|css|html|json|md)
    command -v prettier >/dev/null && prettier --write "$FILE_PATH" 2>/dev/null ;;
  py)
    command -v black >/dev/null && black -q "$FILE_PATH" 2>/dev/null ;;
  go)
    command -v gofmt >/dev/null && gofmt -w "$FILE_PATH" 2>/dev/null ;;
esac
exit 0
~/.claude/settings.json（format-after-edit） 
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Edit|Write|MultiEdit",
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/format-after-edit.sh"
          }
        ]
      }
    ]
  }
}

Notification Hook：等待提示通知

Claude 長時間跑任務時，你往往切換去做別的事。 Notification Hook 在 Claude 需要確認（permission_prompt）或等待輸入（idle_prompt）時， 主動發 Slack 通知把你叫回來。

~/.claude/hooks/notify-slack.sh 
#!/bin/bash
INPUT=$(cat)
NOTIF_TYPE=$(echo "$INPUT" | python3 -c "import sys,json; print(json.load(sys.stdin).get('notification_type',''))")
MESSAGE=$(echo "$INPUT" | python3 -c "import sys,json; print(json.load(sys.stdin).get('message',''))")

SLACK_URL="$SLACK_WEBHOOK_URL"
[ -z "$SLACK_URL" ] && exit 0

case "$NOTIF_TYPE" in
  permission_prompt) ICON=":bell:"  ; TITLE="Claude 需要你的確認" ;;
  idle_prompt)       ICON=":zzz:"   ; TITLE="Claude 在等待輸入" ;;
  *) exit 0 ;;
esac

PAYLOAD=$(printf '{"text":"%s *%s*: %s"}' "$ICON" "$TITLE" "$MESSAGE")
curl -s -X POST "$SLACK_URL" -H "Content-Type: application/json" -d "$PAYLOAD" >/dev/null
exit 0
~/.claude/settings.json（Notification Hook） 
{
  "hooks": {
    "Notification": [
      {
        "matcher": "permission_prompt|idle_prompt",
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/notify-slack.sh"
          }
        ]
      }
    ]
  }
}
💡
設定 SLACK_WEBHOOK_URL

Slack Webhook URL 屬於敏感資訊，絕對不要寫進 settings.json。在 ~/.bashrc 或 ~/.zshrc 加入：
export SLACK_WEBHOOK_URL="https://hooks.slack.com/services/..."
腳本執行時即可讀取。Windows 使用者可在系統環境變數或 ~/.profile 加入相同設定。

延伸：SessionStart 注入 Git 上下文

Stop Hook 是 session 結束後動作。SessionStart 則是 session 開始時執行—— 可以在 Claude 開始工作之前，自動把 Git 分支、最近 commit、待辦事項注入為初始 context， 讓 Claude 一開口就知道現在專案的狀態。

~/.claude/hooks/inject-context.sh 
#!/bin/bash
PROJECT_DIR="$CLAUDE_PROJECT_DIR"
[ -z "$PROJECT_DIR" ] && PROJECT_DIR="$(pwd)"
cd "$PROJECT_DIR" || exit 0

echo "## 目前專案狀態（SessionStart 自動注入）"
echo ""
echo "分支：$(git branch --show-current 2>/dev/null || echo '(非 git 專案)')"
echo ""
echo "最近 5 個 commit："
git log --oneline -5 2>/dev/null || echo "  (無 git 歷史)"
echo ""
echo "工作樹變更："
git status --short 2>/dev/null || echo "  (乾淨)"
echo ""
echo "TODO 清單："
grep -rn "TODO:" src/ 2>/dev/null | head -5 || echo "  (無待辦)"
exit 0
~/.claude/settings.json（SessionStart） 
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "~/.claude/hooks/inject-context.sh"
          }
        ]
      }
    ]
  }
}

腳本的 stdout 輸出會自動注入到 Claude 的初始 context—— 不需要你每次手動說「現在在 main 分支、有 3 個未提交的變更」，Claude 一開始就知道。

ℹ️
SessionEnd vs Stop — 差別在哪裡？

Stop 在每次 agent 回應結束後觸發，一次 session 中可能觸發多次（每次 Claude 說完話就觸發一次）。SessionEnd 則在整個 session 關閉時才觸發一次。寫工作日誌通常用 Stop 或 SessionEnd 都可以；如果想每次回應都記一筆，用 Stop；想要整個 session 只記一次總結，用 SessionEnd。
