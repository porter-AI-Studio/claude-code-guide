第 15 章 · Part 6：MCP Plugin

MCP 是什麼？

Model Context Protocol——讓 Claude 與任何外部工具、服務、資料庫溝通的標準協定。比自訂工具更標準，比 Hooks 更強大。

一句話定義

MCP（Model Context Protocol） 是 Anthropic 制定的開放標準， 定義了 AI 模型如何與外部工具溝通。 有了 MCP，Claude Code 可以直接呼叫你的資料庫、操作瀏覽器、讀取 Obsidian 筆記—— 只要有對應的 MCP Server。

MCP vs 內建工具 vs Hooks

比較維度內建工具HooksMCP Server 🚀
用途 讀寫檔案、執行 shell 攔截 Claude 的動作 連接外部服務、擴充能力
觸發 Claude 主動呼叫 事件自動觸發 Claude 主動呼叫
標準化 Anthropic 內建 自訂腳本 開放協定，跨平台共享
範例 Read, Edit, Bash 預防 rm -rf / 查詢 Postgres、控制瀏覽器

MCP 能做什麼？

  • 資料庫操作——讓 Claude 直接查詢 PostgreSQL、MongoDB、SQLite
  • 瀏覽器自動化——控制 Chrome 做 E2E 測試、截圖、填表
  • 雲端服務——讀寫 Google Drive、Notion、GitHub Issues
  • Obsidian 整合——搜尋筆記、建立連結、更新 daily note
  • 自訂 API——把公司內部 API 包成工具讓 Claude 呼叫
  • IoT / 工具——連接任何支援 MCP 協定的系統

MCP Server 生態

社群與官方已有大量現成的 MCP Server：

Server功能來源
@modelcontextprotocol/server-filesystem本地檔案讀寫（指定目錄）官方
@modelcontextprotocol/server-githubGitHub Repos / PR / Issues官方
@modelcontextprotocol/server-postgresPostgreSQL 查詢官方
@modelcontextprotocol/server-brave-searchBrave 搜尋引擎官方
mcp-obsidianObsidian vault 操作社群
@executeautomation/playwright-mcp-serverPlaywright 瀏覽器自動化社群
ℹ️
MCP 是開放標準

MCP 協定是開源的，任何人都可以寫 MCP Server。完整的官方 Server 清單和社群貢獻可在 github.com/modelcontextprotocol/servers 找到。
