第 12 章 · Part 5：Skills

官方六大類 Skills

官方已經幫你準備好幾類 Skill——問對問題就會自動觸發。

什麼是 Skills？

Skills 是 Claude Code 的可重複使用工作流程。把常用任務的完整步驟封裝成一個 Slash Command， 一句話啟動，Claude 自動按照流程走。

和直接問 Claude 的差別：Skills 有明確的觸發條件、結構化的執行流程、 以及可共享的標準化輸出。

Skills vs 直接問 Claude

直接問 ClaudeSkill
觸發方式自然語言描述Slash command
流程一致性每次可能不同固定標準流程
可共享只在你的 session可放 git 讓團隊共用
文件化無有 TRIGGER 說明
適用時機一次性、探索性任務重複性、標準化任務
💡
Skills 的本質

Skills 其實就是放在特定目錄下的 Markdown 檔案，裡面包含執行指示。Claude 在對話開始時載入，偵測到符合 TRIGGER 條件的請求就自動套用。下一章會教你如何使用，第 14 章教你自己寫。
